# Number Classifier

## Description

This project is a simple Python program that classifies numbers.  
It is a learning exercise designed to practice functions and conditional statements in Python.

The program identifies if a number is even or odd and if it is positive, negative, or zero.

## How it works

1. The program asks the user to enter a number.
2. The function `is_even()` checks if the number is even or odd using the modulo operator.
3. The function `number_type()` determines if the number is positive, negative, or zero.
4. The function `show_result()` prints the final classification results.
5. The program displays the results on the screen.

The program uses conditional statements to analyze the input number.  
It returns the classification based on mathematical conditions.

## Status

> The project is currently running as a simple console program and it is helping students understand basic Python logic.
